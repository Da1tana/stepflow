# План: запись действий (MVP)

Статус: **техническое направление проверено по документации Chrome; реализация и E2E-проверка впереди** · ветка `feat/recording-mvp` · дата: 2026-11-25

Цель: пользователь запускает запись, кликает по странице, видит шаги в боковой панели, останавливает запись, инструкция сохраняется локально. Без скриншотов.

## 1. Подтверждённые ограничения Chrome

- `activeTab` выдаётся при явном вызове расширения. Открытие popup — один из таких вызовов; также подходит команда из `commands`.
- В Chrome доступ сохраняется при навигации в пределах того же origin и отзывается при переходе на другой origin или закрытии вкладки.
- Для `chrome.scripting.executeScript` нужны `scripting` и доступ к целевой странице; временный host-доступ даёт `activeTab`.
- Большинство событий и методов `chrome.tabs` не требуют разрешения `tabs`. Само разрешение `tabs` главным образом открывает чувствительные поля `url`, `pendingUrl`, `title`, `favIconUrl` в результатах Tabs API. Поэтому не добавлять `tabs` только ради `onUpdated`/ `onRemoved`.
- `chrome.sidePanel.open()` требует пользовательского взаимодействия. Вызывать его непосредственно из обработчика клика в popup, не после асинхронного сообщения в service worker.

**Важно:** документация подтверждает API-контракт, но не заменяет E2E-проверку конкретного потока StepFlow. В тестах отдельно подтвердить вызов `sidePanel.open()`, same-origin reinjection и безопасный отказ после cross-origin.

## 2. Выбранная схема

**Разрешения:** существующие `sidePanel`, `storage` + новые `activeTab`, `scripting`. Не добавлять `host_permissions`, `tabs`, `webNavigation`, `content_scripts` без отдельного обоснования и проверки.

**Запуск:**
1. Пользователь открывает popup через иконку StepFlow или горячую клавишу.
2. Нажимает «Начать запись».
3. Обработчик клика в popup напрямую вызывает `chrome.sidePanel.open()` (если панель нужно открыть) и запускает согласованный start-flow. Не полагаться на перенос transient user activation через асинхронный round trip.
4. Service worker проверяет допустимость URL и внедряет recorder через `chrome.scripting.executeScript`.
5. Боковая панель показывает ход записи и шаги. Если доступ отозван, показывает понятную инструкцию повторно вызвать StepFlow.

Клик внутри уже открытой боковой панели сам по себе не является надёжным способом получить новый `activeTab` grant. Для возобновления после cross-origin перехода пользователь должен снова вызвать расширение.

**Безопасная альтернатива (не в MVP):** `optional_host_permissions` для конкретного сайта с запросом через `chrome.permissions.request`. Не запрашивать доступ ко всем сайтам по умолчанию.

## 3. Поток данных

```
Popup click → direct sidePanel.open() + start request
                  ↓
Service worker → executeScript(files) → content/recorder.js
                                      ↓ trusted click descriptor
Service worker validates sender + descriptor → storage.local draft
Side panel observes storage changes → renders steps
Stop → save Guide locally; Cancel → discard draft
```

## 4. Конфиденциальность

Скрипт на странице отправляет только **описание элемента**: роль и безопасную метку ограниченной длины. Никогда:

- значения `input`, `textarea`, `select`, `contenteditable`, текст форм;
- содержимое полей `type=password` и подписи, которые могут раскрывать введённые значения;
- HTML, полный текст страницы, `document.title`, query-строку и hash URL;
- синтетические события (`isTrusted === false`).

Не использовать произвольный текст страницы как fallback. Для полей ввода использовать нейтральные метки по типу («поле ввода», «поле пароля») и не читать `value`, `placeholder`, `aria-label` или произвольные атрибуты, если они могут содержать пользовательские данные. Regex-фильтры — только дополнительная защита, не гарантия.

## 5. Названия шагов (i18n, en + ru)

| Элемент | Шаг |
|---------|-----|
| Кнопка / `role=button` / submit | Нажмите «Сохранить» |
| Ссылка | Перейдите по ссылке «Тарифы» |
| Флажок / переключатель | Нажмите на флажок «Запомнить меня» (без состояния) |
| Радио | Выберите вариант «Ежемесячно» |
| Выпадающий список | Откройте список «Страна» (без выбранного значения) |
| Текстовое поле | Нажмите на поле ввода |
| Поле пароля | Нажмите на поле пароля |
| Вкладка / пункт меню | Откройте вкладку / пункт меню |
| Без названия | Нажмите на кнопку / ссылку |

## 6. Надёжность и навигация

- Состояние в `chrome.storage.local` (`sf.recording`): статус, tabId, origin (если безопасно доступен в момент grant), шаги.
- Запись шагов сериализуется очередью в service worker.
- Слушатели `chrome.tabs.onUpdated` и `chrome.tabs.onRemoved` регистрируются синхронно при запуске service worker.
- На `onUpdated` использовать tab ID и `changeInfo.status`; не полагаться на чтение URL всех вкладок. При начале загрузки поставить запись на паузу; после `status === 'complete'` попробовать внедрить recorder заново.
- Если reinjection успешен — продолжить запись (same-origin сценарий). Если отказал — оставить состояние paused и показать просьбу повторно вызвать StepFlow (cross-origin/restricted page).
- Закрытие вкладки → сохранить черновик как инструкцию, если есть шаги; пустую сессию удалить.
- При запуске браузера с незавершённым черновиком — сохранить/восстановить как черновик сессии, но не возобновлять инъекцию автоматически.
- Отмена удаляет черновик без сохранения.
- Запрещённые страницы: `chrome://`, `chrome-extension://`, `edge://`, `about:`, `devtools://`, `view-source:`, Chrome Web Store, `data:`, PDF viewer.
- Только главный frame, одна активная сессия.

## 8. Критерии готовности MVP

- Пользователь может начать запись, сделать несколько кликов, увидеть шаги, остановить и сохранить инструкцию локально.
- Отмена удаляет черновик.
- Same-origin navigation восстанавливает recorder после загрузки.
- Cross-origin navigation приостанавливает запись и требует повторного вызова расширения.
- Поля и введённые значения не попадают в storage ни в одном сценарии.
- Unit, E2E, static validation и CI проходят.
- README и карта проекта соответствуют фактическому поведению.
